# Analysis

This folder contains the Excel-based analysis used in the market risk measurement and hedging project.

The workbook includes:

- Construction of a $1 billion portfolio across five Hong Kong / China equity indices
- USD conversion using the USD/HKD exchange rate
- Daily portfolio return calculations
- Beta estimation against the S&P 500
- Historical Simulation VaR
- Delta-Normal VaR
- Monte Carlo VaR
- Expected Shortfall analysis
- VaR and ES comparison
- Futures hedging analysis
- Put-option hedging analysis
- Scenario comparison across hedging strategies
