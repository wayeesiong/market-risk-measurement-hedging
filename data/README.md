# Data

This folder contains the market data used in the market risk measurement and hedging analysis.

The dataset includes historical observations for:

- Hang Seng Index (HSI)
- FTSE China 50 Index
- Hang Seng TECH Index
- Hang Seng China Enterprises Index
- Hang Seng China-Affiliated Corporations Index
- S&P 500
- USD/HKD exchange rate

The data are used to construct the USD-denominated portfolio, calculate daily returns, estimate portfolio beta and measure market risk.
